# Overview

## What is Claude Code?

A CLI-native coding agent that lives in your terminal.

- Reads and writes files, runs commands, manages git
- Works on your real project --- not a throwaway copy
- Permission model (and optional bash sandbox) keep you in control
- Context window as demand-paged working memory

## What this deck covers

Each lesson maps to a slide deck covering core concepts.

- **01 -- Foundations** (1--2): The Prompt + Permissions
- **02 -- Making It Personal** (3--8): Terminal, prompts, tools, CLAUDE.md, context
- **03 -- Power Features** (9--14): Models, access control, flags, commands, skills, hooks
- **04 -- Autonomous Use** (15--21): MCP, sub-agents, teams, checkpoints, git, headless, worktrees

## The trajectory

Start supervised. End autonomous.

The more structure you give Claude --- instructions, tests, project conventions --- the more safely you can let it run independently.
